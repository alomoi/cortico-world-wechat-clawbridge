# 图片表情包

**本质就是图片**：和发普通图走同一条链路，没有额外协议字段。

## 怎么用

参数里写 `sticker:<名字>`：

```json
clawbridge_send({
  "text": "【害羞】你别这么说呀",
  "images": ["sticker:害羞"]
})
```

→ 微信收到：一条文字「😳你别这么说呀」+ 一张 `害羞.png`

## 素材放哪

插件启动时会自动建第一个目录，往里丢文件即可：

| 目录 | 归属 |
|---|---|
| `<dataDir>/clawbot/stickers/` | 桥（推荐，插件会自动创建） |
| `<companion>/workspace/stickers/` | 桌宠工作区（她也能自己放/自己用） |
| `config.json` 的 `stickerRoots` | 你额外指定的目录 |

**按顺序命中，先找到先用。**

## 命名规则

- **参数里不用写扩展名**：`sticker:害羞` 会依次尝试
  `害羞.png` → `害羞.jpg` → `害羞.jpeg` → `害羞.gif` → `害羞.webp`
- 文件名就是名字，可以中文。
- 大小写不敏感。

### 可选：`index.json`（别名）

不想改文件名时，可以在目录里放：

```json
{ "害羞": "shy.png", "笑": "laugh.gif" }
```

有它就优先按别名找，没有就按同名文件找。

## 对素材的建议（插件不强制）

| 项 | 建议 |
|---|---|
| 格式 | PNG（透明背景最好）/ GIF（动图）/ JPG |
| 尺寸 | 240×240 上下，最大别超过 640×640 |
| 文件大小 | 建议 ≤ 2 MB，越小明信片化越快 |
| 长宽比 | 建议正方形，微信会按比例显示 |

> 插件只挡 `maxMediaBytes`（默认 32 MiB）这个安全上限，其余不做缩放或格式转换——
> 表情包是给人看的，交给素材本身决定。

## 排错

| 回执 | 含义 |
|---|---|
| `失败:第N条 表情「委屈」不在素材表` | 目录里没有同名文件，或 `index.json` 没这条 |
| `失败:第N条 图片过大` | 超过 `maxMediaBytes` |
